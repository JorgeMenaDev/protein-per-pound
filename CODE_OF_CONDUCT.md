# Code of conduct

Protein per Pound follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep discussion about the food and the code. Harassment, personal attacks and discrimination are not tolerated in issues, pull requests or anywhere else this project lives.

If something goes wrong, report it privately to the maintainer through [GitHub](https://github.com/JorgeMenaDev) or with GitHub's "Report content" option. Reports are handled confidentially.
